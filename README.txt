The site keeps the supplied Clarah's Café images and includes a clean assets folder.
To add more pictures:
1. Put the new image in assets/
2. Open gallery.html (or the page where you want it)
3. Add another gallery/card image using the same pattern.
No uploaded image is generated or modified by this project.

Open index.html in Chrome or Edge to preview locally.
